# \## What This Port Changes

# \- Built from Psych Engine 1.0.4 for the HTML5 (browser) target.

# \- The mod's Lua scripts were rewritten in Haxe, because browsers can't run Lua. Gameplay, events and endings are meant to match the original.

# \- Story Mode, the Mods menu and the debug editors are disabled in the browser version.

# \- Songs were converted from .ogg to .mp3 for browser support.

# 

# No original art, music or charts were changed.

# 

# \---

# 

# \## How to Play

# Open the hosted page, wait for it to load (\~120 MB), and press \*\*Enter\*\*.

# Browsers only allow sound after your first key press.

# 

# To host it yourself, upload the whole folder to a web server and open `index.html`.

# It won't work by double-clicking the file locally.
